## Rules that apply to every offer

Bluehost says promotional prices are for new customers and for the initial term only. Plans renew at the regular rate. Some offers cannot be combined with others. Because of this, a code from a coupon site may do nothing.

## How to check if a code is valid

1. Add your plan to the cart on the [Bluehost site](host:bluehost).
2. Look for a promo code field and apply the code.
3. Compare the total before and after. If it does not change, the code did not work.
